# @paperclipai/plugin-graphify

A [Paperclip](https://paperclip.ing) plugin that integrates [Graphify](https://github.com/nicholasgriffintn/graphify) knowledge graphs into your agent workflows and project UI.

## Features

### Agent Tools

When active, the plugin registers four tools available to all agents:

| Tool | Description |
|------|-------------|
| `graphify_query` | Natural language query against the knowledge graph (`--dfs`, `--budget` options) |
| `graphify_path` | Find the path between two nodes |
| `graphify_explain` | Everything the graph knows about a specific node |
| `graphify_build` | Build or update the graph from the project workspace (`--update`, `--mode deep`) |

### Graph Visualization

A **Graphify** tab appears on each project page with:

- **Communities** — bubble chart of the top communities by node count, click to drill into nodes
- **Force Graph** — interactive force-directed layout (via `graph.html` generated by graphify)
- **Additional views** — any other HTML files in the graphify output directory auto-appear as tabs

Views support fullscreen expand (Escape to exit).

### Managed Skill

The plugin injects a skill into the company skill library that teaches agents when to prefer Graphify tools over expensive grep/find for structural codebase questions.

## Installation

Install from npm in the Paperclip plugin UI:

```
@paperclipai/plugin-graphify
```

Or from a local registry:

```bash
npm install @paperclipai/plugin-graphify --registry http://localhost:4873/
```

## Configuration

Two ways to point the plugin at your graph data:

| Scope | How |
|-------|-----|
| **Per-project** | Set `GRAPHIFY_GRAPH_PATH` in the project's environment variables (Configuration tab). Accepts a path to the directory or directly to `graph.json`. |
| **Company-wide default** | Set the local folder on the plugin settings page. Applies to all projects that don't have their own `GRAPHIFY_GRAPH_PATH`. |

## Development

```bash
# Install dependencies
npm install

# Build
npm run build

# Type check
npm run typecheck
```

### Building from source

The build uses esbuild with the Paperclip plugin SDK's bundler presets. Output goes to `dist/`:

- `dist/manifest.js` — plugin manifest
- `dist/worker.js` — worker with tools and data handlers
- `dist/ui/index.js` — UI bundle (React, provided by host)
